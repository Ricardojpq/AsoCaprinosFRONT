# Assets - Images

## Instrucciones para la imagen de fondo del certificado

Para que el certificado funcione correctamente, necesitas colocar el archivo `certificadoBase-1.jpg` en esta carpeta.

### Pasos:
1. Toma el archivo `certificadoBase-1.jpg` que tienes
2. Cópialo a `/workspace/src/app/assets/images/certificadoBase-1.jpg`
3. El componente automáticamente lo detectará y lo usará como fondo

### Ubicación esperada:
```
src/app/assets/images/certificadoBase-1.jpg
```

### Notas:
- La imagen se muestra con opacidad reducida (15%) para que el texto sea legible
- Puedes controlar si mostrar o no la imagen de fondo usando el parámetro `showBackgroundImage`
- La imagen se ajusta automáticamente al tamaño del certificado
